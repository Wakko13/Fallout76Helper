## Uncertain / worth double-checking

The Barrel, Stock, Magazine, and Muzzle tables above use only the summarized effect line from the
source (e.g. "Superior range") rather than exact numeric stat deltas, since Fextralife's Assault Rifle
page didn't expose the same per-stat breakdown (Range: +X, Accuracy: +Y) for those sections that it did
for the Receiver table — treat the numeric deltas on the Combat Rifle and Hunting Rifle pages as a
rough guide to relative magnitude if you need numbers. The Short/Long Recon Scope's Gunsmith 5 gate is
notably higher than the equivalent scope on other 5.56mm rifles (which gate at Gunsmith 3), so it's
worth confirming in-game rather than assuming a typo. As always, exact numeric stat values and material
counts shift with balance patches, so treat the above as a strong starting point rather than a
guaranteed-current recipe.
