The Automatic-family receivers (Automatic, Tweaked Automatic, Powerful Automatic) switch the Combat
Rifle to full-auto fire, which is what lets this weapon flex between Rifleman-style semi-auto builds
and Commando-style automatic builds — see [Rifles and carbines](../rifles-and-carbines/) for that split.

## Uncertain / worth double-checking

The Steadfast Receiver's materials cell came back blank on Fextralife's table — everything else about
that row (effect, Gunsmith 3 gate) was present, just not the crafting cost. The Long Recon Scope that
some other 5.56mm rifles carry doesn't appear to be listed for the Combat Rifle at all on this source;
worth checking in-game if you're specifically hunting for a top-tier zoom option. As always, exact
numeric stat values and material counts shift with balance patches, so treat the above as a strong
starting point rather than a guaranteed-current recipe.
