For how mod slots and Weapons Workbenches work in general, see
[Weapon and armor mod basics](../../faq/weapon-and-armor-mod-basics/). For the Gatling Plasma's role as
a heavy sustained-fire plasma weapon, its plasma-cartridge ammo, and how it compares to the rest of the
energy-weapon family, see [Energy weapons](../energy-weapons/).

**A naming note that cross-checks another page in this series:** the Gatling Plasma's Receiver slot
includes a **Calibrated Capacitor** option (crit-damage focused). That confirms what
[Gauss Rifle mod options](../gauss-rifle-mods/) flags — "Calibrated" is a Laser/Plasma-family mod name,
not a Gauss one; the Gauss line's equivalent slots use Standard/Quick/Large/Swift/Perforating/Piercing/
Stinging/Prime naming instead. Fextralife's Gatling Plasma page returned only vague, partly-garbled
values this session (e.g. an unclear "+81 value" figure with no consistent unit), so the table below
relies on Nukes & Dragons' cleaner percentage-based data throughout.

## Uncertain / worth double-checking

No crafting materials or perk requirements were found for any Gatling Plasma mod on either source
checked this session — Nukes & Dragons doesn't publish materials at all, and Fextralife's page came
back too degraded to use (garbled value formatting, an unverifiable "Gunsmith 4 (INT)" blanket perk
claim that isn't corroborated elsewhere, so it's omitted above rather than repeated as fact). Treat
every row's Perk/Materials columns as needing a live-wiki check before farming for a specific build.
