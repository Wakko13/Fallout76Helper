For how the armor mod slot system works in general (material tiers, the single misc slot, underarmor
linings being separate), see [Weapon and armor mod basics](../../faq/weapon-and-armor-mod-basics/). For
where Metal Armor sits relative to Leather/Combat/Robot/etc., see
[Light and combat armor sets](../light-and-combat-armor-sets/).

Metal Armor's material mods (Painted/Polished/Alloyed/Enameled/Shadowed Metal) also show up on **Robot
Armor** — see [Robot Armor mod options](../robot-armor-mods/), which shares this same material-mod list
per cross-referenced wiki summaries. Data below is for the **chest piece**; limb pieces use the same mod
names at smaller base resistance values.

## Weight class

| Mod | Effect | Perk required | Materials |
| --- | --- | --- | --- |
| Light (standard) | Baseline weight and resistance | — | Not documented on reachable sources |
| Medium (Sturdy) | Weight +40%, all resistances +30% | Not documented | Not documented on reachable sources |
| Heavy | Weight +65%, all resistances +65% | Not documented | Not documented on reachable sources |

## Material/Resistance mods

Percentages are relative bonuses over the piece's base resistance at its current weight class, per
Nukes & Dragons.

| Mod | Effect | Perk required | Materials |
| --- | --- | --- | --- |
| Standard | No bonus | — | — |
| Painted Metal | Energy Resistance +35%, Weight +10%. Reported as known by default. | — | Not documented on reachable sources |
| Polished Metal | Physical +20%, Energy +40%, Radiation +40%, Weight +30% | Not documented | Not documented on reachable sources |
| Shadowed Metal | Stealth in Shadows +0.05 | Not documented | Not documented on reachable sources |
| Alloyed Metal | Physical +25%, Energy +10%, Radiation +10%, Fire +15%, Cryo +15%, Weight +20% | Not documented | Not documented on reachable sources |
| Enameled Metal | Physical +5%, Energy +5%, Radiation/Fire/Cryo/Poison +18% each, Weight +15%. Reported as scrap-learned (low % chance). | Not documented | Not documented on reachable sources |

## Misc mod (single slot)

Only one of these can be active at a time — this is the single "misc mod slot" per piece described in
[Weapon and armor mod basics](../../faq/weapon-and-armor-mod-basics/).

| Mod | Effect | Perk required | Materials |
| --- | --- | --- | --- |
| Pocketed | Carry Weight +10 | Not documented | Not documented on reachable sources |
| Deep Pocketed | Carry Weight +20 | Historically Armorer rank 1; current gating unclear | Not documented on reachable sources |
| Lighter Build | Action Points +10 | Not documented | Not documented on reachable sources |
| Ultra-Light Build | Action Points +20 | Historically Armorer rank 1; current gating unclear | Not documented on reachable sources |
| Padded | Reduce incoming explosive damage 15% | Not documented | Not documented on reachable sources |
| Dense | Reduce incoming explosive damage 30% | Historically Armorer rank 1; current gating unclear | Not documented on reachable sources |

## Uncertain / worth double-checking

Metal Armor's mod data quality is essentially the same story as Leather's:

- **Fextralife's per-item Metal Chest Piece page has no mod table** — base stats only, several fields
  showing "??" placeholders. All effect numbers above come from Nukes & Dragons instead.
- **No crafting materials could be confirmed for any Metal Armor mod on a reachable source.**
  fallout.fandom.com and fallout.wiki both returned HTTP errors (402/403) on every page tried for this set
  (material mod pages, the general armor-mods page), consistent with what happened researching Leather
  Armor — this looks like a block on the fetch tool rather than missing content, so a different search
  phrasing is unlikely to get past it.
- **"Known by default" vs. "scrap-learned" status** for Painted/Enameled Metal is carried over from
  wiki-summary snippets surfaced via search, not a directly-fetched primary table — reasonably likely
  correct by analogy with Leather Armor's confirmed Boiled/Girded/Treated/Studded pattern, but not
  independently verified for Metal specifically.
- **Perk gating** for the misc-slot mods (Deep Pocketed, Dense, Ultra-Light Build) is the same
  historically-Armorer-rank-1, currently-unclear situation flagged in the Leather Armor mods entry — worth
  confirming in-game.
- The **Metal-Robot material mod overlap** claim (Alloyed Metal and Enameled Metal both applying to Robot
  Armor) rests on a wiki-summary snippet, not a page this session could load directly — treat it as
  probable but re-verify if it matters for a specific build.
