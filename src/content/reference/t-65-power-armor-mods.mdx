For general power armor mechanics — chassis vs. pieces, fusion cores, entering/exiting, repair
stations — see [power armor basics](../../faq/power-armor-basics/). For how T-65 stacks up
against the other five endgame models and how to buy its plans (Regs, Vault 79, for Gold Bullion),
see [Power armor sets](../power-armor-sets/).

T-65 shares the same four-slot functional-mod pool (torso/legs/arms/helmet) documented in
[T-45's mod file](../t-45-power-armor-mods/) — every mod name and effect below matches T-45's
one-for-one, with no T-65-exclusive functional mod found on any source checked. What
distinguishes T-65 is the **highest base physical and energy resistance of any power armor in the
game**, and the second-highest radiation resistance after Strangler Heart — but, notably,
**T-65 has no full-set bonus at all**, unlike Union, Strangler Heart, and Vulcan.

## No set bonus

Multiple sources describe T-65 explicitly as "the tankiest all-rounder with high resistances but
no set bonus" — wearing all six T-65 pieces grants nothing beyond the standard universal power
armor set benefit (42% damage reduction / 90% radiation damage reduction that any complete power
armor set provides). If you're chasing a Union-style or Vulcan-style full-set perk, T-65 doesn't
have one; its case is built entirely on base resistance numbers.

## Uncertain / worth double-checking

- **"No set bonus" is the headline claim of this file and comes from secondary community sources
  (NerdBurglars, general tier-list commentary), not a primary patch-notes citation** — worth an
  in-game sanity check, especially since T-65 has received balance attention before. If Bethesda
  ever adds a T-65 set bonus in a future update, this file would need revisiting.
- **T-65 torso base stats** (for context, not a mod): 732 Damage Resistance / 504 Energy Resistance
  / 667 Radiation Resistance at level 50 per Nukes & Dragons — these are the highest DR/ER figures
  of any power armor torso checked in this initiative, consistent with T-65's "best physical/energy
  resistance in slot" reputation from `power-armor-sets.mdx`.
- **Rad Scrubbers' absence from T-65's helmet pool is inferred from omission**, not a direct
  "this mod doesn't exist for T-65" statement — a broader search confirmed Rad Scrubbers is
  compatible with Excavator, Raider, T-45, T-51b, T-60, Ultracite, and X-01, notably **not** listing
  T-65, Union, Hellcat, Strangler Heart, or Vulcan.
- **No T-65-exclusive functional mod (torso/leg/arm/helmet) was found on any source** — unlike
  Strangler Heart (Welded Rebar) or Vulcan (Reflection Assembly, Gimbal Bracers, Ultracite Bracers,
  Elastic Servos), T-65 appears to rely entirely on the shared base pool with no exclusive mod to
  compensate for its lack of a set bonus.
- **Materials for every mod on this page were not found on any reachable source** — same gap as
  most of T-45's pool; Fextralife's per-mod T-65 pages weren't reachable this session (direct URL
  guesses 404'd) and fallout.wiki/fallout.fandom.com returned 403 on every direct fetch attempt.
