For general power armor mechanics — chassis vs. pieces, fusion cores, entering/exiting, repair
stations — see [power armor basics](../../faq/power-armor-basics/). For how Ultracite power armor
stacks up against the other five models and how to get it (a complete free set from "Belly of the
Beast," extra piece plans afterward from Taggerdy's terminal, level 50 crafting requirement), see
[Power armor sets](../power-armor-sets/). For the full functional-mod pool Ultracite mostly shares
and the perk-requirement caveats common to every power armor set, see
[T-45 Power Armor mod options](../t-45-power-armor-mods/).

As with every power armor set, there is **no Sturdy/Hardened-style resistance-tier ladder** for
Ultracite — its own base Radiation Resistance is already unusually high (see stats note below),
which is presumably the actual design answer to "how do I resist radiation in this set" rather than
a mod.

## Torso mods (incl. Jet Pack)

Ultracite is the one set in this initiative whose fetched torso mod list included **both Welded
Rebar and Reactive Plates** rather than one replacing the other — ten total mods where every other
set showed nine (Excavator/Raider swap one-for-one) or ten with only Reactive Plates (T-45/T-51/
T-60). Not confirmed whether both are genuinely simultaneously available choices in the same misc
slot or whether this is a data artifact; see Uncertain.

## Uncertain / worth double-checking

- **Whether Welded Rebar and Reactive Plates are truly both simultaneously available on Ultracite,
  or whether this is a data-fetch artifact combining an old and current mod list, is unresolved.**
  Every other set's fetched list showed exactly one of the two, never both. If only one is actually
  obtainable in-game, Reactive Plates (the one shared with T-45/T-51/T-60) is the safer default
  assumption, but this wasn't confirmed either way.
- **Ultracite's base Radiation Resistance (885 at level 50 per Nukes & Dragons) is dramatically
  higher than every other set covered in this initiative** (T-45: 313, T-51: 380, T-60: 607,
  Excavator: 280, Raider: 362) — consistent with Ultracite power armor's reputation as the
  radiation-resistance specialist set, and with [Power armor sets](../power-armor-sets/) describing
  it as "high-tier, strong radiation resistance." Flagged here as a genuinely confirmed, useful
  number rather than an uncertainty, since the mod tables above are thin enough that this base-stat
  fact is arguably the most load-bearing thing in this file.
- **Perk requirements are entirely undocumented for Ultracite** specifically — see
  [T-45 Power Armor mod options](../t-45-power-armor-mods/) Uncertain section for the aggregated
  (unverified) Science!/Armorer rank claims for the shared mod family.
- **Materials for every mod besides Jet Pack were not found on any reachable source for this set** —
  Ultracite's individual per-mod Fextralife pages beyond Jet Pack were not fetched directly this
  session (time/budget constraints across six sets), so absence here reflects "not checked" more
  than "confirmed absent" in most rows.
