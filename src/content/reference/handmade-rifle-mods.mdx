## Uncertain / worth double-checking

**This page is materially incomplete.** Fextralife's Handmade Rifle page only exposed a Receiver mod
table — no Barrel, Stock, Magazine, Sight, or Muzzle tables were present, unlike every other rifle in
this wave (Combat, Hunting, Assault, Lever Action) which all had full multi-category tables on the same
source. The Handmade Rifle unquestionably has those other mod categories in-game (community sources
confirm barrel, stock, magazine, sight, and muzzle mods exist, and a piercing-magazine option is known
to drop capacity to 10 rounds), but the exact mod names, effects, perk gates, and materials for those
categories weren't retrievable this session: `fallout.wiki` and `fallout.fandom.com` (including the
fallout-archive.fandom.com mirror) all returned 402/403 errors on every fetch attempt, and web search
did not surface a complete substitute table. Also note several Receiver rows above (Hardened, Fierce,
Powerful Automatic, Severe, Scorched Killer's) were listed by the source as sharing identical stat
deltas and materials with the base Automatic Receiver, which reads as a likely data-entry shortcut on
Fextralife's part rather than confirmation that those mods are truly numerically identical — worth
spot-checking in-game if the exact differences matter for your build. Treat this file as a partial
reference and re-check a live wiki for the missing categories before relying on it for a full build.
