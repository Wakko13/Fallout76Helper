For how the armor mod slot system works in general (material tiers, the single misc slot, underarmor
linings being separate), see [Weapon and armor mod basics](../../faq/weapon-and-armor-mod-basics/). For
where Trapper Armor sits relative to Leather/Metal/Combat/etc., see
[Light and combat armor sets](../light-and-combat-armor-sets/).

Trapper Armor's material mods (Welded/Tempered/Hardened/Buttressed) are **not** the same family as
Combat Armor's (Reinforced/Fiberglass/Polymer/Brotherhood of Steel) or Metal/Robot Armor's
(Painted/Polished/Alloyed/Enameled). Multiple sources describe Welded/Tempered/Hardened/Buttressed as a
family shared across **Raider, Trapper, and Marine Armor** specifically — see
[Marine Armor mod options](../marine-armor-mods/), which reuses this same list. Data below is for the
**chest piece**; limb pieces use the same mod names at smaller base resistance values.

## Weight class

| Mod | Effect | Perk required | Materials |
| --- | --- | --- | --- |
| Light (standard) | Baseline weight and resistance | — | Not documented on reachable sources |
| Medium (Sturdy) | Weight +40%, all resistances +30% | Not documented | Not documented on reachable sources |
| Heavy | Weight +65%, all resistances +65% | Not documented | Not documented on reachable sources |

## Material/Resistance mods

Percentages are relative bonuses over the piece's base resistance at its current weight class, per Nukes
& Dragons. Crafting materials and scrap-learn chances below come from wiki-summary snippets (fallout.wiki
returned HTTP errors on direct fetch for every Trapper-specific page tried, same as prior waves), so treat
the exact quantities as probable rather than independently confirmed.

| Mod | Effect | Perk required | Materials |
| --- | --- | --- | --- |
| Standard | No bonus | — | — |
| Welded Trapper | All resistances +5-13%, Weight +10%. Reported known by default. | — | Reported: 1x Adhesive, 1x Cloth, 1x Steel |
| Tempered Trapper | Physical Resistance +35%, Fire/Cryo Resistance +15%, Weight +15%. Reported scrap-learned (~0.75% chance). | Not documented | Reported: 1x Adhesive, 1x Cloth, 2x Steel |
| Hardened Trapper | All resistances +15%, Weight +20%. Reported scrap-learned (~0.75% chance). | Not documented | Reported: 1x Adhesive, 1x Cloth, 4x Steel |
| Buttressed Trapper | Physical Resistance +65%, Weight +30%. Reported scrap-learned (~0.75% chance). | Not documented | Reported: 1x Adhesive, 1x Cloth, 5x Steel |

A separate wiki-summary source gives per-level resistance ranges instead of percentages for this same
family (applied to Raider/Trapper/Marine alike): torso Welded +4-10, Tempered +5-15, Hardened +6-20,
Buttressed +7-25; limb Welded +1-6, Tempered +2-8, Hardened +3-10, Buttressed +4-13 (Damage/Energy/
Radiation Resistance together). These numbers don't cleanly reconcile with the Nukes & Dragons percentages
above — likely two different presentations (flat per-level values vs. relative percentage) of the same
underlying mods rather than a contradiction, but neither could be directly verified against a primary
table.

## Misc mod (single slot)

Only one of these can be active at a time — this is the single "misc mod slot" per piece described in
[Weapon and armor mod basics](../../faq/weapon-and-armor-mod-basics/).

| Mod | Effect | Perk required | Materials |
| --- | --- | --- | --- |
| Pocketed | Carry Weight +10 (torso) / reported +5 (limb) | Not documented | Reported similar to Deep Pocketed's materials but lower quantities; not itemized on any reachable source |
| Deep Pocketed | Carry Weight +20 (torso) / +10 (limb) | Armorer (rank not confirmed) | Reported: 3x Adhesive, 3x Cloth, 3x Leather |
| Lighter Build | Action Points +10 (general pattern) — one Trapper-specific source instead reports +2 AP | Not documented | Reported (Trapper-specific, conflicts with above): 1x Adhesive, 3x Cork, 2x Fiberglass, 2x Rubber; scrap-learned |
| Ultra-Light Build | Action Points +20 | Historically Armorer rank 1; current gating unclear | Not documented on reachable sources |
| Padded | Reduce incoming explosive damage 15% | Not documented | Not documented on reachable sources |
| Dense | Reduce incoming explosive damage 30% | Historically Armorer rank 1; current gating unclear | Not documented on reachable sources |
| Pneumatic | Reduce incoming stagger 25% | Not documented | Not documented on reachable sources |
| Asbestos Lining | Fire-resistance oriented; Weight +15% | Not documented | Not documented on reachable sources |
| Lead Lined | Radiation-resistance oriented; Weight +20% | Not documented | Not documented on reachable sources |
| BioCommMesh | Chem Duration +0.5 | Not documented | Not documented on reachable sources |

## Uncertain / worth double-checking

- **Fextralife's per-item Trapper Chest Piece page has no mod table** — same "??" placeholder pattern as
  every other set in this initiative. All effect numbers above come from Nukes & Dragons plus
  wiki-summary snippets, not a directly-loaded wiki table.
- **The Welded/Tempered/Hardened/Buttressed material-mod family being shared across Raider, Trapper, and
  Marine Armor** is the load-bearing assumption for this file's framing. It's supported by consistent
  naming and near-identical crafting-material quantities surfacing for both Trapper and Marine searches
  independently, but neither a Raider Armor page nor a single unified primary source was directly loaded
  to confirm all three share it — treat as probable, not certain.
- **Lighter Build has a genuine conflict** between the generic +10 AP figure used consistently across
  Leather/Metal/Combat/Robot Armor's misc-mod tables and one Trapper-specific source reporting +2 AP with
  a distinct material list (Cork/Fiberglass/Rubber rather than the Pocketed-family Adhesive/Cloth/Leather
  pattern). This may mean Trapper's Lighter Build is a genuinely different mod from the other sets', or it
  may be a source error — worth confirming in-game before relying on either number.
- **The Pocketed limb value of +5 Carry Weight** (vs. the +10 used elsewhere without a stated split) comes
  from a single search-summarized source and wasn't cross-checked; the Deep Pocketed torso/limb split
  (+20/+10) is more consistent with the pattern already confirmed for Combat Armor.
- **Crafting materials for the Welded/Tempered/Hardened/Buttressed tiers** came through via search-engine
  snippets of wiki pages this session couldn't directly load (consistent 402/403 blocks on
  fallout.fandom.com and fallout.wiki), so treat the exact material counts as reasonably likely but not
  independently verified.
- **Perk gating** for Deep Pocketed is confirmed to require *some* rank of Armorer per a secondary source,
  but the specific rank number wasn't stated — the other misc mods' gating is the same
  historically-Armorer-rank-1, currently-unclear situation flagged across every file in this initiative.
