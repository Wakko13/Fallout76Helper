This one is a genuine dead end on research, worth being upfront about rather than papering over: Fextralife's
Zeta Gun page — currently the primary wiki source for this weapon — is a near-empty stub. Its "Zeta Gun Mods"
section has no content at all, and even basic fields like damage, ammo type, fire rate, and minimum level are
left as unfilled placeholders. Broader web searches (including Fallout Wiki/Fandom alternatives, which
returned access errors when fetched directly) turned up no community source with a documented mod list,
material costs, or confirmation of whether this weapon has mod slots in the first place.

No mod table is included here because there is no sourced data to put in one — inventing plausible-sounding
receiver/barrel names for a weapon with zero source coverage would fail the "don't invent mod slots" bar for
this project more than an honest gap would.

## Uncertain / worth double-checking

Everything about this weapon's mod system is uncertain. What's known: the Zeta Gun is classified alongside
other Non-Automatic Pistols (Alien Blaster, Gamma Gun, Plasma Pistol) on Fextralife, and per the
[Pistols and sidearms](../pistols-and-sidearms/) overview it's an alien-themed rare/collector weapon using its
own unique ammo type, in the same spirit as the Alien Blaster — which itself has a very limited mod pool. It
would not be surprising if the Zeta Gun similarly has few or no mods, but that's an inference from a sibling
weapon's pattern, not a sourced fact about this one. Before planning around this weapon at all, check a
current, populated wiki page (or in-game) directly — this page should be revisited once better source data
exists.
