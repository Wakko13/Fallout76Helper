For how mod slots and Weapons Workbenches work in general, see
[Weapon and armor mod basics](../../faq/weapon-and-armor-mod-basics/). For the Gauss Pistol's
charge-shot mechanic, ammo, and Gold Bullion plan cost, see [Energy weapons](../energy-weapons/). For
the Gauss Rifle's version of this same capacitor mechanic, see
[Gauss Rifle mod options](../gauss-rifle-mods/).

**A naming note that matters here:** unlike the Gauss Rifle, where the charge-mechanic mod slot is
genuinely called "Capacitor" (confirmed by the plan name **Plan: Prime Gauss rifle capacitors**), the
**Gauss Pistol's equivalent slot is called "Receiver"** in-game — confirmed by the plan name
**Plan: Prime Gauss pistol receiver**. It does the same job (same Prime effect, same charge mechanic)
under a different slot name, so don't be thrown by the different label between this page and the
Gauss Rifle one. Fextralife's own Gauss Pistol page returned no usable mod table during this research
pass (repeated fetches came back empty), so the table below comes entirely from Nukes & Dragons'
game-data-driven database, which uses **percentage-based** effect values and does not list crafting
materials.

## Uncertain / worth double-checking

This is the thinnest-sourced page in this batch alongside the Ultracite Laser Rifle: Fextralife's
dedicated Gauss Pistol page produced no populated mod table across multiple fetch attempts, so
everything above rests on a single source (Nukes & Dragons), which doesn't publish crafting materials
for any weapon. Nukes & Dragons also didn't list a separate Stock slot for the Gauss Pistol — plausible
for a one-handed weapon, but not independently confirmed. The Prime Receiver's "+65% to Scorched"
figure is Nukes & Dragons' number specifically; the fuller community description for the Gauss Rifle's
Prime Capacitor (+25% base damage, +60% *more* against Scorched on top of that) may apply here too
since both are described as the same underlying mechanic, but that hasn't been independently confirmed
for the pistol specifically. fallout.wiki's dedicated Gauss Pistol page returned HTTP 403 to direct
fetches this session — a known limitation, not a sign the page doesn't exist — and would be worth
checking directly for materials and a fuller Prime Receiver description if you can reach it. If you're
planning a specific charge-build around this weapon, verify exact numbers against a live wiki or
in-game before farming Gold Bullion for plans.
