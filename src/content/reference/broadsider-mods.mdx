For how mod slots and Weapons Workbenches work in general, see
[Weapon and armor mod basics](../../faq/weapon-and-armor-mod-basics/). For how the Broadsider's
one-handed, cannonball-firing niche fits into the rest of the heavy-weapon family, see
[Heavy weapons](../heavy-weapons/).

**A source note up front:** like the Gauss Rifle page in this series, Fextralife's Broadsider page
confirms the three mod slot names (Barrel, Grip, Shot Canister) but its table came back with no
populated effect, perk, or materials cells — consistent with the page's own "??" markers for the
weapon's perk requirement and location fields. The table below comes from Nukes & Dragons' database
instead, which uses percentage-based effect values and doesn't publish crafting materials for any
weapon.

## Uncertain / worth double-checking

No crafting materials were found for any row on any source checked — Fextralife's table was
effectively empty for this weapon (same pattern as the Gauss Rifle page), and Nukes & Dragons
doesn't publish materials at all. Perk gates are unconfirmed for the Barrel and Grip slots; the
Multi Shot Canister is the one row with a confirmed gate, but it's a dedicated plan drop rather than
a Gunsmith perk rank, which is a different unlock pattern than most other weapons in this series —
worth double-checking that plan's drop source (Daily Ops, Supplying Demands, event pools) against a
live wiki if you're specifically farming for it. A web search also surfaced a possible third barrel
option ("Light Barrel") on a Fandom mod-page listing, but its effect text overlapped suspiciously
with the Standard Barrel's own description and it did not appear in Nukes & Dragons' structured
database at all — treated here as unconfirmed and omitted rather than risk inventing a row.
