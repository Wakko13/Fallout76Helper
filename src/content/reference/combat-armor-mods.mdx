For how the armor mod slot system works in general (material tiers, the single misc slot, underarmor
linings being separate), see [Weapon and armor mod basics](../../faq/weapon-and-armor-mod-basics/). For
where Combat Armor sits relative to Leather/Metal/Robot/etc. — this is generally regarded as the most
mod-flexible of the early/mid sets — see [Light and combat armor sets](../light-and-combat-armor-sets/).

Data below is for the **chest piece**; limb pieces share the same mod names, and the misc mod slot has a
documented torso-vs-limb split for Deep Pocketed specifically (see table).

## Weight class

| Mod | Effect | Perk required | Materials |
| --- | --- | --- | --- |
| Light (standard) | Baseline weight and resistance | — | Not documented on reachable sources |
| Medium (Sturdy) | Weight +40%, all resistances (Physical/Energy/Radiation/Poison/Fire/Cryo) +30% | Not documented | Not documented on reachable sources |
| Heavy | Weight +65%, all resistances (Physical/Energy/Radiation/Poison/Fire/Cryo) +65% | Not documented | Not documented on reachable sources |

## Material/Resistance mods

Percentages/values are relative bonuses over the piece's base resistance at its current weight class, per
Nukes & Dragons, cross-checked against a separate wiki summary for the tier order and unlock method.

| Mod | Effect | Perk required | Materials |
| --- | --- | --- | --- |
| Standard | No bonus | — | — |
| Reinforced Combat Armor | All resistances +10%, Weight +10%. Reported first-tier, known by default. At level 50 this is roughly +7 DR/+7 ER on a torso piece per one wiki comparison. | — | Not documented on reachable sources |
| Fiberglass Combat Armor | Physical/Energy +20%, Radiation/Fire/Cryo/Poison +8%, Weight +15%. Reported second-tier, learned by scrapping combat armor. Roughly +10 DR/+10 ER at level 50 on a torso piece per the same comparison. | Not documented | Not documented on reachable sources |
| Polymer Combat Armor | Physical/Energy +10%, Radiation/Fire/Cryo/Poison +20%, Weight +20%. Reported third-tier, learned by scrapping. Roughly +13 DR/+13 ER at level 50 on a torso piece per the same comparison. | Not documented | Not documented on reachable sources |
| Brotherhood of Steel (Combat Armor) | Physical +40%, Energy/Fire/Cryo +10%, Radiation +25%, Poison +20% | Not documented | Not documented on reachable sources |
| Shadowed Combat Armor | Stealth in Shadows +0.05 | Not documented | Not documented on reachable sources |

## Misc mod (single slot)

Only one of these can be active at a time — this is the single "misc mod slot" per piece described in
[Weapon and armor mod basics](../../faq/weapon-and-armor-mod-basics/).

| Mod | Effect | Perk required | Materials |
| --- | --- | --- | --- |
| Pocketed | Carry Weight +10 | Not documented | Not documented on reachable sources |
| Deep Pocketed | Carry Weight +20 (torso variant) / +10 (limb variant) | Historically Armorer rank 1; current gating unclear | Not documented on reachable sources |
| Lighter Build | Action Points +10 | Not documented | Not documented on reachable sources |
| Ultra-Light Build | Action Points +20 | Historically Armorer rank 1; current gating unclear | Not documented on reachable sources |
| Padded | Reduce incoming explosive damage 15% | Not documented | Not documented on reachable sources |
| Dense | Reduce incoming explosive damage 30% | Historically Armorer rank 1; current gating unclear | Not documented on reachable sources |
| Pneumatic | Reduce incoming stagger 25% | Not documented | Not documented on reachable sources |
| Asbestos Lining | Fire-resistance oriented; Weight +15% | Not documented | Not documented on reachable sources |
| Lead Lined | Radiation-resistance oriented; Weight +20% | Not documented | Not documented on reachable sources |
| BioCommMesh | Chem Duration +0.5 | Not documented | Not documented on reachable sources |

## Uncertain / worth double-checking

- **Fextralife's per-item Combat Armor Chest Piece page has no mod table** — weight and value are present
  but damage resistance, minimum level, and other fields all show "??" placeholders. All effect numbers
  above come from Nukes & Dragons plus wiki-summary snippets surfaced via search, not a direct wiki table.
- **No crafting materials could be confirmed for any Combat Armor mod** on a source this session could
  actually load. As with Leather and Metal Armor, every fallout.fandom.com and fallout.wiki page attempted
  (Reinforced, Fiberglass, Polymer, the general "Fallout 76 armor mods" page) returned HTTP 402/403 errors —
  a systematic block, not a per-page gap.
- **The Reinforced/Fiberglass/Polymer tier order and default-vs-scrap-learned status** comes from a
  search-engine summary of a blocked wiki page, not a page this session directly verified — treat as
  probably right (it's internally consistent with the same known-default → scrap-learned pattern
  confirmed for Leather Armor) but not confirmed firsthand.
- **"Brotherhood of Steel" as a Combat Armor material mod name** is unusual enough (it reads like a
  faction-reputation-vendor variant rather than a scrap-tier mod) that it's worth confirming in-game before
  relying on it — it wasn't cross-referenced against a second source.
- **Perk gating** for the misc-slot mods is the same historically-Armorer-rank-1,
  currently-unclear situation noted in the Leather and Metal Armor mods entries.
