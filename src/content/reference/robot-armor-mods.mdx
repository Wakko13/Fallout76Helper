For how the armor mod slot system works in general (material tiers, the single misc slot, underarmor
linings being separate), see [Weapon and armor mod basics](../../faq/weapon-and-armor-mod-basics/). For
where Robot Armor sits relative to Leather/Metal/Combat/etc., see
[Light and combat armor sets](../light-and-combat-armor-sets/).

**Robot Armor's material mods appear to be the exact same list as Metal Armor's** — Painted Metal, Polished
Metal, Shadowed Metal, Alloyed Metal, and Enameled Metal all show up on both sets' data (see
[Metal Armor mod options](../metal-armor-mods/)) with matching effect numbers on Nukes & Dragons, and a
separate wiki-summary snippet explicitly describes Alloyed Metal and Enameled Metal as applying to "metal
and robot armor" pieces. Data below is for the **chest piece**; limb pieces share the same mod names.

## Weight class

| Mod | Effect | Perk required | Materials |
| --- | --- | --- | --- |
| Light (standard) | Baseline weight and resistance | — | Not documented on reachable sources |
| Medium (Sturdy) | Weight +40%, all resistances +30% | Not documented | Not documented on reachable sources |
| Heavy | Weight +65%, all resistances +65% | Not documented | Not documented on reachable sources |

## Material/Resistance mods

Identical set of mods and (per Nukes & Dragons) identical percentage effects to Metal Armor's material
mods — see the note above and [Metal Armor mod options](../metal-armor-mods/) for the same table with
Metal-specific framing.

| Mod | Effect | Perk required | Materials |
| --- | --- | --- | --- |
| Standard | No bonus | — | — |
| Painted Metal | Energy Resistance +35%, Weight +10% | — | Not documented on reachable sources |
| Polished Metal | Physical +20%, Energy +40%, Radiation +40%, Weight +30% | Not documented | Not documented on reachable sources |
| Shadowed Metal | Stealth in Shadows +0.05 | Not documented | Not documented on reachable sources |
| Alloyed Metal | Physical +25%, Energy +10%, Radiation +10%, Fire +15%, Cryo +15%, Weight +20% | Not documented | Not documented on reachable sources |
| Enameled Metal | Physical +5%, Energy +5%, Radiation/Fire/Cryo/Poison +18% each, Weight +15% | Not documented | Not documented on reachable sources |

## Misc mod (single slot)

Only one of these can be active at a time — this is the single "misc mod slot" per piece described in
[Weapon and armor mod basics](../../faq/weapon-and-armor-mod-basics/). Deep Pocketed and Ultra-Light Build
plans are separately confirmed to exist specifically for Robot Armor chest (their plan names appear on
wiki plan-listing pages), which supports this slot working the same way it does on the other sets.

| Mod | Effect | Perk required | Materials |
| --- | --- | --- | --- |
| Pocketed | Carry Weight +10 | Not documented | Not documented on reachable sources |
| Deep Pocketed | Carry Weight +20 | Historically Armorer rank 1; current gating unclear | Not documented on reachable sources |
| Lighter Build | Action Points +10 | Not documented | Not documented on reachable sources |
| Ultra-Light Build | Action Points +20 | Historically Armorer rank 1; current gating unclear | Not documented on reachable sources |
| Padded | Reduce incoming explosive damage 15% | Not documented | Not documented on reachable sources |
| Dense | Reduce incoming explosive damage 30% | Historically Armorer rank 1; current gating unclear | Not documented on reachable sources |
| Pneumatic | Reduce incoming stagger 25% | Not documented | Not documented on reachable sources |
| Asbestos Lining | Fire-resistance oriented; Weight +15% | Not documented | Not documented on reachable sources |
| Lead Lined | Radiation-resistance oriented; Weight +20% | Not documented | Not documented on reachable sources |
| BioCommMesh | Chem Duration +0.5 | Not documented | Not documented on reachable sources |

## Uncertain / worth double-checking

Robot Armor was the thinnest of the four sets to research:

- **Fextralife has no dedicated, working per-item page for the Robot Chest Piece under the URL pattern
  that worked for the other three sets** (`Robot+Chest+Piece` 404'd; `Robot+Armor+Chest+Piece` loaded but,
  like the others, has no mod table — just base stats and "??" placeholders).
- **The claim that Robot Armor's material mods are identical to Metal Armor's** is the load-bearing
  assumption in this file. It's supported by two independent-looking signals (matching names/numbers on
  Nukes & Dragons, and a wiki snippet explicitly saying Alloyed/Enameled apply to "metal and robot armor"),
  but neither source could be directly loaded and fully verified — fallout.fandom.com and fallout.wiki both
  returned HTTP 402/403 on every Robot Armor page tried. Treat the shared-list claim as probable, not
  certain, and don't assume every single material mod necessarily behaves identically on Robot vs. Metal
  (e.g., a Robot-specific radiation-resistance skew given Robot Armor's general "some built-in radiation
  resistance" framing elsewhere on this site wouldn't be surprising, but nothing found confirms or denies
  it).
- **No crafting materials or explicit perk gates were found for any Robot Armor mod** on a reachable
  source — same situation as the other three sets in this wave.
- If Robot Armor turns out to have any genuinely unique mods beyond the shared Metal-Armor list (a
  robot-themed cosmetic material, for instance), this file would be missing them — nothing surfaced during
  research pointed at any, but the search coverage here was thinner than for the other three sets.
